# PR2 · 独立符号的状态来源与组合验证

## 实验定义

使用同一 ISA 模型、同一配置和两个独立符号初始状态，分别推演下列两条普通指令（原始 little-endian 字节）：

| Trace | 指令 | 机器码 |
|---|---|---|
| A | r2 = r1 | bf12000000000000 |
| B | r2 += 4 | 0702000004000000 |

随后明确假设 A 紧接着 B 顺序执行（A 正常完成、无中间写入、同一线程与架构状态、匹配位宽）。不假设任意两个独立 Trace 都能组合，也不据此认定真实程序的控制流可达。符号的显示名在两次运行中可能不同，也可能碰巧相同；两种情况都不得作为判断身份的依据。

下面是依 [Linux eBPF ISA](https://docs.kernel.org/bpf/standardization/instruction-set.html) MOV/ADD64 的独立数学预期，不是实测 Isla 输出：

- A 读 r1 的入口值 a，写 r2 值 t；t=a。A 执行前的 r2 可任意，不决定 t。
- B 读 r2 的入口值 b，写 r2 值 c；c=(b+4) mod 2^64。
- 在给定连续执行假设下，A 的 r2 出口与 B 的 r2 入口代表同一状态位置，故 b=t；组合结果 c=(a+4) mod 2^64。B 的 r2 出口与入口不是同一个状态版本。

实际 Trace 中 a/t/b/c 可能是常量、局部变量、定义的别名或表达式；必须以事件与定义为准，不能假设恰好出现四个独立声明。

## 关联方法

研究与实现的对象是实际两份 Trace，而不是只将上面的数学关系翻译成 SMT。优先基于 [ITL 与 Islaris 的现有语义及实现](sail-isla.md#islaris-与证明系统)；以下为最低安全条件，具体数据结构以实际 AST 和证明证据为准：

1. **隔离原始符号。** 每个独立 Trace 具有独立命名空间，先保留局部符号的原始标识、声明、sort/位宽、定义、约束及引用关系。变量重命名必须一致、无捕获，不得因两个 Trace 使用相同 vN 而自动合并。
2. **标记来源与状态版本。** 从真实有序事件及定义确定输入、输出、局部临时符号。对寄存器状态记录架构寄存器身份、访问器/字段（若有）、读/写及顺序、值的表达式、sort、所在 Trace 与相关路径前提。入口和出口是不同状态版本；不能按寄存器名字将本次写入前后的值都合成同一个变量。若 trace 缺少判断状态的必要信息，研究如何从模型/API 获得它，不编造。
3. **建立连接。** 本例只允许从明确的顺序状态传递关系推导 A 的最终 r2 与 B 的初始 r2 对应；被写入的寄存器使用最新出口状态，未写入的值在有明确 frame 依据时沿用。对证明同一状态值的两个独立输入/输出符号可用显式等式连接，或以统一 canonical symbol 表达。若一端是复合表达式，可在保持 sort 和定义作用域的前提下用表达式替换或新符号加等式。保留原始定义与相关路径约束；没有证据的临时符号、不同寄存器或不同状态版本保持独立。
4. **输出关联证据。** 记录原始两端的 Trace/事件定位、状态位置及版本、原始值/表达式、类型、关联理由/前提、canonical identity 或保留的等式，以及无法判断的项目。生成一份组合且可机器检查的表示，让同一值不再以无关独立变量呈现；不能只生成表格而未在实际表达式中建立连接。优先输出规范化 ITL AST 或保留 ITL 语义的可机器检查表示，允许另导出 SMT-LIB 供验证，不要求最终 NodeSummary schema。

同一符号和等值表达式是两个层次：符号名重命名只能改变标识，不能改变语义；基于程序状态迁移添加等式是组合不同推演的语义约束；消去或统一被证明等值的变量又是对该约束的保持语义变换。分开这三步，便于今后提出可验证的证明义务。

## 正确性判据

使用原始 Trace 经上游 parser/转换生成的实际语义对象、事件关联和独立 ISA 预期；不得从规范化输出反推原始输入。以下要求实际 Islaris/Coq 检查，辅以 SMT 或等价的可检查推导。

- **Islaris 实例证明：** 将实际 A、B 转换为 Islaris 可用的 Coq Trace 定义。利用其寄存器 points-to、declare/define/read/write/assume 规则，证明两条独立 Trace 的状态效果与顺序连接。可按 continuation 形式证明：若最终状态满足后续证明所需条件，则初始状态满足执行 A 后 B 的 Hoare double；从任意合法的初始 r1=x、r2=y 出发，A 的 r2 出口为 x，B 的 r2 出口为 bvadd(x,4)，r1 未被改写（按实际 frame 证明）。明确实际 PC、模型寄存器字段、类型和所有 Assume/AssumeReg 所要求的条件；若出现 Cases，不能忽略实际分支、异常或失败。允许采用上游等效的 WP/trace composition 表述；不得凭空手写 A/B 的 Trace 作为唯一被证明对象。证明检查器必须编译实际实例源码，使用原始/转换定义并记录实际 theorem 名、命令及 `Print Assumptions` 或等价检查。不得增加未证明的假设掩盖目标；说明上游理论本身依赖的公理和信任边界。
- **基线组合：** 对两个已隔离的局部关系 C_A、C_B，依据明确的 A→B 状态传递形成 C_link = C_A ∧ C_B ∧ (b=t)，必要时包括实际 frame、sort 和路径条件。保持其真实声明及约束。对本例选定正常执行的可观察接口至少保留 r1_in、r2_out；若额外输出入口 r2 或其它寄存器，也必须保存其适用的约束与 frame 语义。
- **语义正确性：** 证明该接口上的关系与实验定义的独立 ISA 预期一致。至少对 C_link ∧ (r2_out ≠ bvadd(r1_in, 4)) 进行反例查询，期望 UNSAT；同时验证正常条件下存在执行，且不因组合将原本任意的 64 位入口值无故限制为部分取值。仅 SAT 一个样本不足以证明覆盖；可用按定义消去内部变量后比较接口关系、给出对任意输入成立的构造性 witness，或求解量化/等价的约束检查。若实际模型包含额外前置条件，先交代适用域及其依据，不可为了得到 UNSAT 临时补加假设。
- **规范化正确性：** 比较 C_link 与实际统一符号后的 C_norm 在同一外部接口（以及实际保留的其他状态效果/条件）上的投影关系，内部变量可通过定义替换或存在量化消去。证明双向包含或可检查的等价变换；不能直接比较互不相同的局部变量名，不能只验证已加上的 b=t。可在 Coq 中证明局部 substitution/rename 的语义保持，或将真实、已核对的两份语义关系交给 SMT 检查；若使用 SMT 投影，则保留 ITL→关系提取的实际映射与适用前提，并独立检查提取是否忠实。Hoare double 的安全性或单向蕴含本身不能替代双向关系证明。可选用同一 Sail/Isla 模型连续推演 A;B 作为附加交叉参照，但不能替代独立推演及关联证据。
- **最小反例：** 使用同一对 Trace 的一致变量改名（包含人为制造局部名称碰撞，标明派生测试而非实测 Trace），正确关联不变；未建立连接的版本允许错误的输出反例；将 B 的 r2 出口当作入口、或把 A 原本未读取的 r2 入口当作 A 出口，应由规则拒绝或被独立语义判据证伪。位宽不相容时不做无依据统一。若真实 Trace 中某一错误关系恰好等价于正确关系，则选用上述能实际区别正确和错误的反例，不伪造失败证据。

交付实际求解输入、输出、映射关系与限制。SAT 的反例、unknown、超时或证据不足不能当作证明成功。上述验收仅针对这两个独立算术指令和明确的顺序假设；一般跨节点状态版本、条件路径、别名和内存统一需要后续单独验证。Islaris 检查证明的是实际 ITL 及给定前提下的实例结论；本轮不把 eBPF Sail→Isla Trace 的翻译正确性、整个 eBPF ISA 或通用绑定算法的正确性视为已获证明。
