# Islaris symbol binding example

Two independent Isla runs generate ITL for `r2 = r1` and `r2 += 4`. For the stated same-thread order, with normal completion and no intervening write, the composer links the latest A writes of `r2` and `PC` to the corresponding B entry reads. `r1` and the little-endian setting carry through as frame state.

```text
Sail eBPF words → Isla A.itl and B.itl
  ├─ Islaris direct converter → Coq trace definitions → Proof.v
  └─ isla-lang AST → scoped relations + binding log → Z3
```

## Relation and proof boundaries

`bind.ml` numbers source events from one, tracks writes by register and version, and gives the two local symbol scopes distinct names. It checks each register read against its current state. The baseline retains both local scopes and the explicit boundary equalities. The normalized relation binds B's corresponding entry symbols to the A exit terms with SMT `let` bindings. Both preserve the read and assumption constraints. The reader rejects unhandled events, forks, register fields, and mismatched sorts.

The SMT interface retains entry and exit `r1`, `r2`, PC, and endianness. The ISA relation defines a witness for every 64-bit pair `(r1_in, r2_in)` and every ITL PC under the little-endian precondition. Its exit witness is `(r1_in, r1_in + 4, pc_in + 2)` with the original endianness and the trace widths. Checking both implications against this graph establishes coverage and the observable effect. A further pair of implications compares the normalized and baseline relations. The derived tests consistently freshen B's local IDs, remove the `r2` connection, connect either wrong state version, and mutate the B entry width.

The Islaris proof uses an explicit continuation to state the final register ownership after each instruction and after the pair. The raw Coq inputs are generated by Islaris. Before concatenating, isla-lang freshens every B declaration, definition, and use because Islaris substitutes through the entire tail. Coq checks the freshened input against the same renaming applied to the raw B definition. It also checks that both raw traces are flat and declare only bitvector symbols before the proof drops enum metadata. [Upstream reuse](UPSTREAM.md)

This example checks the selected interface at the ITL layer. It assumes the supplied Sail model, the Sail-to-Isla translation, the Isla engine, the parser/converter, and the correctness of the example's SMT extraction. The proof and SMT checks cover the recorded arithmetic instructions under the explicit order and endianness assumptions. The model's PC representation, machine-code fetch, memory semantics, and whole-ISA translation validation lie outside this instance.
